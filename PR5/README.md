# Практическая работа № 5. Классификатор и анализ метрик

**Выполнил:** Алмасов Арсен

**Цель работы:** изучить процесс обучения модели логистической регрессии для выполнения бинарной классификации клиентов и оценить качество её предсказаний.

В ходе практической работы была создана и обучена модель логистической регрессии для разделения клиентов на две категории. Для организации процесса обработки данных использовался `Pipeline`, позволяющий объединить необходимые этапы подготовки данных и обучения модели. Для оценки результатов классификации была построена матрица ошибок, с помощью которой можно определить количество правильных и неправильных предсказаний. Также были рассчитаны основные метрики качества: Accuracy, Precision, Recall и F1-score. Их анализ позволил рассмотреть точность классификации, способность модели правильно определять положительный класс и общий баланс между Precision и Recall. В результате были изучены основные принципы бинарной классификации и способы оценки эффективности модели машинного обучения.
