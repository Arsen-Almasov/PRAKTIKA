# Практическая работа № 7. Случайный лес

**Автор:** Алмасов Арсен

**Цель работы:** изучить особенности алгоритмов дерева решений и случайного леса, а также сравнить их эффективность при решении задачи классификации.

В ходе практической работы была выполнена предварительная обработка данных, необходимая для обучения моделей машинного обучения. Для классификации использовались два алгоритма: `DecisionTreeClassifier` и `RandomForestClassifier`. После обучения моделей были проведены сравнение и оценка их результатов с помощью метрик Accuracy и F1-score. Для построения случайного леса использовалось 100 деревьев решений, что позволяет объединять результаты нескольких моделей и повышать стабильность предсказаний. Дополнительно был построен график важности признаков, помогающий определить, какие характеристики данных оказывают наибольшее влияние на результаты классификации. В результате были рассмотрены основные принципы работы двух алгоритмов, выявлены различия между ними и изучены способы оценки качества моделей машинного обучения.
