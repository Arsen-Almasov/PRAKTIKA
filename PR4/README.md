# Практическая работа № 4. Регрессионная модель

**Выполнил:** Алмасов Арсен

**Цель работы:** изучить принципы построения и обучения модели линейной регрессии для прогнозирования дневного дохода клиентов на основе имеющихся данных.

В ходе практической работы была разработана и обучена модель линейной регрессии. Для подготовки данных использовались `Pipeline` и `ColumnTransformer`, применённые в практической работе № 3. Данные были разделены на обучающую и тестовую выборки, что позволило проверить качество модели на новых данных. Для оценки точности прогнозирования использовались метрики MAE, RMSE и R². Дополнительно был выполнен анализ коэффициентов регрессии для определения влияния отдельных признаков на результат, а также построен график, позволяющий сравнить предсказанные значения с фактическими. В результате были изучены основные этапы создания регрессионной модели и способы оценки её качества.
