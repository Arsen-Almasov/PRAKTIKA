## О проекте

Данный репозиторий представляет собой сборник из семи практических работ, посвящённых изучению основ машинного обучения с использованием Python. В ходе выполнения заданий рассматриваются методы анализа и обработки данных, построение моделей регрессии и классификации, а также оценка их эффективности.

Каждая практическая работа посвящена отдельному этапу работы с данными и моделями машинного обучения.

## Используемые инструменты и библиотеки

- **Python** — основной язык программирования.
- **Jupyter Notebook** — среда для написания и выполнения кода.
- **Pandas** — обработка данных и работа с таблицами.
- **NumPy** — выполнение числовых операций.
- **Matplotlib** — визуализация результатов анализа.
- **Scikit-learn** — подготовка данных, обучение и проверка моделей.
- **Jupyter / VS Code** — запуск и редактирование ноутбуков.

## Список практических работ

### ПР1. Основы Python и работа с Jupyter Notebook

Изучение возможностей Python и среды Jupyter Notebook. Загрузка набора данных `tips.csv`, знакомство с его структурой и выполнение базовых операций для просмотра и обработки табличной информации.

### ПР2. Разведочный анализ данных (EDA)

Исследование набора данных `customers_dirty.csv`. Анализ типов и распределений признаков, поиск отсутствующих значений и возможных выбросов. Построение графиков и подготовка выводов на основе полученных результатов.

### ПР3. Подготовка данных к машинному обучению

Освоение основных методов предварительной обработки данных. Заполнение пропусков в числовых признаках медианными значениями, преобразование категориальных переменных и масштабирование числовых данных. Разделение набора данных на обучающую и тестовую части.

### ПР4. Построение моделей регрессии

Применение линейной регрессии для прогнозирования числового показателя дохода. Проверка качества предсказаний с помощью метрик MAE, RMSE и \(R^2\). Интерпретация полученных результатов и изучение графиков.

### ПР5. Бинарная классификация

Реализация модели логистической регрессии для решения задачи классификации на два класса. Измерение качества работы модели с использованием Accuracy, Precision, Recall и F1-score. Дополнительно рассматривается матрица ошибок для анализа правильных и ошибочных предсказаний.

### ПР6. Классификация текстовых данных

Разработка моделей для определения категорий текстовых сообщений. Сравнение способов преобразования текста в числовые признаки с помощью `CountVectorizer` и `TfidfVectorizer` в сочетании с наивным байесовским классификатором. Оценка результатов по метрикам Accuracy и F1-score, а также анализ ошибок классификации.

### ПР7. Деревья решений и случайный лес

Изучение и сравнение алгоритмов на основе деревьев решений. Обучение моделей на одном наборе данных, оценка их качества на тестовой выборке и сравнение полученных результатов. Исследование важности признаков с помощью визуализации.

## Установка и запуск

### 1. Установите Python

Убедитесь, что Python установлен и доступен из командной строки.

### 2. Установите необходимые библиотеки

Выполните команду в терминале:

```bash
pip install pandas numpy matplotlib scikit-learn jupyter nbformat
```

### 3. Откройте проект

Откройте нужный файл `notebook.ipynb` в Jupyter Notebook или Visual Studio Code.

### 4. Выполните код

Запускайте ячейки ноутбука последовательно, начиная с первой. Изучите сформированные таблицы, графики и результаты работы моделей.

## Заключение

В рамках проекта изучаются основные инструменты машинного обучения на Python. Практические задания охватывают исследование данных, их предварительную обработку, построение регрессионных и классификационных моделей, оценку качества предсказаний и интерпретацию результатов.

Полученные навыки позволяют лучше понять последовательность решения задач машинного обучения — от первоначального анализа набора данных до проверки эффективности обученной модели.
