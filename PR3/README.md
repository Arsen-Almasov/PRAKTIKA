# Практическая работа № 3. Сборка пайплайна предобработки данных

**Выполнил:** Алмасов Арсен

В ходе выполнения практической работы был разработан конвейер предобработки данных (Pipeline) с использованием инструментов машинного обучения на Python. Основной целью работы являлась автоматизация подготовки исходных данных для дальнейшего обучения моделей.

В процессе работы были рассмотрены и реализованы основные этапы обработки данных: заполнение пропущенных значений, кодирование категориальных признаков, в частности названий городов, а также масштабирование числовых признаков. Для выполнения этих операций были использованы соответствующие методы предварительной обработки данных.

Дополнительно исходный набор данных был разделён на обучающую и тестовую выборки. Все этапы преобразования были организованы таким образом, чтобы обучать параметры предобработки только на обучающих данных, что позволяет избежать утечки данных (Data Leakage) и получить более объективную оценку качества модели.

**Результат работы:** создан единый пайплайн, объединяющий несколько этапов предобработки данных. Его использование упрощает подготовку информации, обеспечивает последовательность преобразований и позволяет применять одинаковые правила обработки как к обучающей, так и к тестовой выборке.
