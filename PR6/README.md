# Практическая работа № 6. Классификация текстов

**Выполнил:** Алмасов Арсен

**Цель работы:** изучить методы классификации текстовых данных и сравнить эффективность `CountVectorizer` и `TfidfVectorizer` при использовании наивного байесовского классификатора.

В ходе практической работы была выполнена подготовка текстовых данных, включающая очистку текста и разделение набора данных на обучающую и тестовую выборки. Для преобразования текстов в числовой формат применялись два метода векторизации: `CountVectorizer`, учитывающий частоту появления слов, и `TfidfVectorizer`, позволяющий учитывать значимость слов в документах. На основе полученных признаков были обучены две модели наивного байесовского классификатора. Для сравнения их результатов использовались метрики Accuracy и F1-score, позволяющие оценить качество предсказаний. Дополнительно был проведён анализ ошибок классификации, чтобы выявить возможные причины неправильного определения категорий текстов. В результате были рассмотрены основные этапы обработки текстовых данных и изучены различия между двумя подходами к векторизации.
